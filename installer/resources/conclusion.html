Alldebrid Streaming Script is installed

Quit your browser completely (⌘Q) and open it again.

What was installed
/Library/AlldebridStreaming/ – the native host (host.js, messaging.js, run.sh)
/Library/Google/Chrome/NativeMessagingHosts/com.alld.node.json
Plus the same file for Microsoft Edge and Firefox, if they are installed.
Uninstall

Run this in Terminal:
sudo bash /Library/AlldebridStreaming/uninstall.sh
