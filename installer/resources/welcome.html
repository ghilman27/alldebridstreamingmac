This will install the Alldebrid Streaming Script, which lets the Alldebrid browser extension open streams in VLC.

Requirement: Node.js must be installed (from nodejs.org, Homebrew, or nvm).

Upgrading from version 1.0.0? Delete the old file first:
~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.alld.node.json
Chrome prefers that old file over the new one, and it points to a location that no longer exists.


Click “Continue” to continue the setup.
