Alldebrid Streaming Script
What this script does?
  - Create com.alld.node Folder in HOME folder
  - Create NativeMessagingHosts Folder in LIBRARY/APPLICATION SUPPORT/GOOGLE/CHROME
  - Copy config.js, host.hs, messaging.js and run.sh to com.alld.node Folder
  - Copy com.alld.node.json to NativeMessagingHosts Folder 
Uninstall Alldebrid Streaming Script
Run the following command to uninstall Alldebrid Streaming Script.   $ sudo bash /Library/AlldebridStreaming/1.0.0/uninstall.sh
